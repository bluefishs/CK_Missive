## 🏪 Store 系統

### 統一的 Store 模式
使用 `createBaseStore` 工廠函數創建一致的 Store：

```typescript
export const useDocumentStore = createBaseStore<
  Document,
  CreateDocumentRequest,
  UpdateDocumentRequest
>(
  new DocumentApiService(),
  {
    name: 'document-store',
    enableDevtools: true,
    enableImmer: true
  }
);
```

### Store 功能
- ✅ 統一的 API 抽象
- ✅ 自動錯誤處理
- ✅ 載入狀態管理
- ✅ DevTools 支援
- ✅ Immer 不可變更新
