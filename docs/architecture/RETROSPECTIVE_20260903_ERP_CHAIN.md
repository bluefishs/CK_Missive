## 3. 五個共同形狀（不是五個 bug）

這兩天修的十幾件事，形狀只有五種。下一次遇到同形的，先想這一節。

**① 同一事實多份，改一處漏其餘。** 三表同步白名單有四份（`field_sync`＋`crud.py`＋`pm/cases.py`×2）；承攬案排序兩處實作，我改在沒人走的那份；匯出／範本／匯入三套表頭。修法一律是「抽單一來源＋守門判自抄」，靜態 grep 找得到想到的寫法，**打端點才找得到沒想到的**。

**② 沒有起點的鏈。** 夜間吹哨者、SystemNotification、LINE 全部活著，但沒有請款的案子永遠不會被催——90 張。標案到建案的回指欄位、程式、端點都在，但 0 筆，因為沒有人從標案頁建案。**程式路徑活著而資料是 0，要分「沒人走」與「走不通」。**

**③ 一張表裝三種東西而沒有欄位標明。** 報價單裝投標 draft、承攬報價、成案錨點，靠 case_code 段落與人的記憶分辨，於是「XLS 只對 02、01 不可誤刪」是口訣不是查詢條件。`quote_kind` 之後才能寫成 WHERE。

**④ 新資料進來，舊的錯位才看得見。** 請款一建入，weekly 100 立刻 RED 87：三表存未稅、總表含稅。金額語意（未稅／含稅）在系統裡從來沒有一個地方寫死。

**⑤ 驗證的替身。** dry-run 用外層 rollback 而成案函式內部 commit（同一教訓第二次）；驗證腳本讀 `data.items` 而 items 在頂層；空範本讓匯入 500 而不是 400。**驗證要打端點、要印原始形狀、要做負向對照**——這三句今天各救了一次。
